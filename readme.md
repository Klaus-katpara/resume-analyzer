# AI Resume Analyzer

A Django-based web application that analyzes resumes and provides:

## 🚀 Features
- Upload PDF resume
- Extract text using PyPDF2
- Detect skills automatically
- Match with job roles
- Generate downloadable PDF report

## 🛠 Tech Stack
- Django
- Python
- Bootstrap
- PyPDF2
- ReportLab
